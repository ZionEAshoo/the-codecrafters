## The Summary of GO Arrays:

Arrays are used to store multiple values of the same type in a single variable, instead of declaring separate variables for each value.

The 'var' keyword and ':=' are used to declear an array in GO. 

In Go, arrays have a fixed length. The length of the array is either defined by a number or is inferred by the compiler.

*In Go, array indexes start at 0. That means that [0] is the first element, [1] is the second element.
*We can also change the value of a specific array element by referring to the index number.
