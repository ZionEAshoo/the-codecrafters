##  The Summary of GO output functions:

Print(), Println() and Printf() are the three functions to output text in GO.

*The Print() function prints its arguments with their default format.
*The Println() prints a whitespace between the arguments, and a newline is added at the end.
*The Printf() function first formats its argument based on the given formatting verb and then prints them.

Go offers several formatting verbs that can be used with the Printf() function. Examaples includes; %v, %T, %b, %d, %s, %t etc.
