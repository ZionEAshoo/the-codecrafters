## The Summary of GO Variables:

In GO, Variables store data value. Int, float32, bool and strings are type of variables.

Variables are decleared with either the 'var' keyword or the ':=' sign.

In GO, we can declare multiple variables on the same line and also multiple variables in a block.

------------------------------------------------


### The rules below guide the way we name GO variables:

A variable name must start with a letter or an '_'

A variable name cannot start with a digit.

A variable name can only contain 'a-z, A-Z, 0-9, and _ '

Variable names are case-sensitive.

There is no limit on the length of the variable name.

A variable name cannot contain spaces.

The variable name cannot be any Go keywords.

*Common methods used in naming variable with more than one word includes camel-case, pascal case and snake-case.
